#Google Spam Policies Checker


An authoritative diagnostic engine and agentic audit skill designed to inspect web pages, HTML source code, and content drafts against the official **Google Web Search Spam Policies** (Google Search Essentials).

Identifies algorithmic demotion risks and manual action exposure across all 17+ official categories:
- **Scaled Content Abuse** (mass unoriginal AI generation & scraping)
- **Site Reputation Abuse / "Parasite SEO"** (with EEA vs. Non-EEA distinctions)
- **Expired Domain Abuse**
- **Link Spam & Thin Affiliation** (unqualified commercial/affiliate links)
- **Hidden Text & Micro-Links** (distinguishing black-hat tricks from accessible UI)
- **Cloaking, Sneaky Redirects & Back-Button Hijacking**
